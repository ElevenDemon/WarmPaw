# 待确认政策清单（不入库）

以下事项在正式确定前，不应让模型生成数值或服务承诺。请由运营填写依据、审核人、生效日后，另行整理为可发布知识正文。

| 事项 | 需要确认的内容 |
| --- | --- |
| 服务覆盖 | 实际城市、区域、服务时间、节假日安排、可接宠物类型 |
| 服务标准 | 基础服务包含项、单次服务时长、特殊需求是否承接 |
| 预约变更 | 最早/最晚预约时间、改期截止时间、已付款取消条件 |
| 退款 | 各状态退款比例、手续费、办理渠道、到账时间、优惠处理 |
| 上门授权 | 钥匙交接、密码传递与删除、提前入户、无法入户处理 |
| 媒体隐私 | 拍摄范围、访问权限、保留期限、下载与删除政策 |
| 责任保障 | 保险实际覆盖、免责范围、损失核实与赔付流程 |
| 异常应急 | 服务响应时间、送医授权、失联处置、费用垫付与承担 |
| 客服投诉 | 人工在线时段、受理渠道、响应及处理时限 |
| 喂养师规则 | 入驻材料、等级、拒单处理、收益结算与申诉 |

PRD 中的目标、原型价格和计划功能，应先核实后再转化为对外承诺。
